# FPL Mini-League Planner

Transfer plans that beat your mini-league, not the template. Paste your FPL team or league link, pick a strategy (Protect lead, Balanced, Chase), and get the top 3 transfer plans with a reason for each move.

Status: phase 2 (expected-points model). See `docs/SPEC.md` for the build plan.
